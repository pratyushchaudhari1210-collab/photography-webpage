# 📸 Photography Showcase Page

A clean, minimalist web page designed to showcase photography work. Built using **HTML5** and **CSS3**, this project focuses on sleek typography, balanced layouts, and image presentation.


## ✨ Features

- **Minimalist Design:** Clean aesthetic centered on showcasing visual media.
- **Semantic HTML5:** Built using structured, modern markup for optimal readability and accessibility.
- **Custom CSS Styling:** Styled from scratch with custom layout rules, spacing, and image alignment.
- **Image Optimization:** Demonstrates smooth scaling and layout balance for high-resolution images.

## 🛠️ Tech Stack

- **HTML5** – Page structure and content markup
- **CSS3** – Layout, typography, colors, and responsive design
